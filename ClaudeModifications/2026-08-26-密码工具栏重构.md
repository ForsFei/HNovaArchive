# 密码工具栏重构与边框修复

**日期**: 2026-08-26  
**类型**: 重构 / 界面修复  
**影响范围**: `README.md`、`src/HDecompressHelper/MainWindow.xaml`、`src/HDecompressHelper/MainWindow.xaml.cs`、`src/HDecompressHelper/Models/AppSettings.cs`、`src/HDecompressHelper/ViewModels/MainViewModel.cs`、`tests/HDecompressHelper.Tests/JsonPersistenceTests.cs`、规划记录

---

## 问题描述

密码区域原先包含启用、显隐和常驻安全提示，占用两行空间；用户希望密码始终启用并明文显示，将输入框移到解压引擎右侧，同时把视图和背景切换靠右排列。单行重构后，工具栏可用高度处于临界值，在部分 DPI 布局下底边框被裁切。

## 根因分析

旧设置模型仍保存 `UsePassword` 和 `IsPasswordVisible`，界面也依赖 `PasswordBox` 覆盖层及双向同步代码，无法直接形成始终可编辑的单行密码输入。布局重构后，工具栏第二行扣除 8px 顶部间距只剩约 52px，而 1px 边框、20px 垂直内边距和 31px 控件合计约需 53px，因此底边会在 DPI 取整时消失。

## 修改内容

**文件**: `src/HDecompressHelper/ViewModels/MainViewModel.cs`

**修改前**:

```csharp
var password = UsePassword ? NewTaskPassword : string.Empty;
```

**修改后**:

```csharp
var password = NewTaskPassword;
```

同时移除密码启用和显隐属性、命令及设置读写逻辑。空文本仍按无密码处理。

**文件**: `src/HDecompressHelper/MainWindow.xaml`

**修改前**:

```xml
<RowDefinition Height="190" />
<!-- 引擎/显示在第一行，密码开关、掩码输入和安全提示在第二行 -->
```

**修改后**:

```xml
<RowDefinition Height="156" />
<!-- 左侧引擎，中部明文密码列表，右侧视图和背景切换 -->
```

窗口启用 `UseLayoutRounding` 和 `SnapsToDevicePixels`，工具栏增加稳定的垂直余量，保证 1px 圆角底边完整显示。

**文件**: `src/HDecompressHelper/Models/AppSettings.cs`、`tests/HDecompressHelper.Tests/JsonPersistenceTests.cs`

删除 `UsePassword` 和 `IsPasswordVisible` 两个过期字段及其往返断言。旧版 JSON 中的遗留字段会被当前反序列化器忽略，密码和成功密码列表继续保留。

**文件**: `README.md`、`task_plan.md`、`findings.md`、`progress.md`

更新第四版功能、默认密码行为、性能边界、布局决策和最终验证记录。

## 设计考量

- 始终启用密码不会触发额外密码扫描：空密码不传给 CLI，正常成功路径不读取候选密码列表。
- 保留可编辑下拉框和删除按钮，继续支持成功密码选择与持久化。
- 移除界面常驻安全提示以符合最新需求，但 README 继续说明密码会明文写入设置、历史和日志。
- 工具栏保留额外高度并采用像素对齐，避免不同系统缩放比例再次裁切边框。
- 已通过格式检查、Release 构建和 60 项测试；实际 Release 窗口确认底边连续完整。
